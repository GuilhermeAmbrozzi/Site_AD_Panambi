# Site AD Panambi

Site institucional da **Igreja Evangélica Assembleia de Deus de Panambi/RS**, desenvolvido com HTML5, CSS3 e JavaScript.

O projeto tem como objetivo disponibilizar informações sobre a igreja, sua história, departamentos, projetos, templos e formas de contato, oferecendo uma navegação moderna, acessível e totalmente responsiva para diferentes dispositivos.

# Responsividade

O projeto foi desenvolvido para proporcionar boa experiência de navegação em:

- Smartphones
- Tablets
- Notebooks
- Monitores Full HD (1920×1080)
- Monitores Ultrawide (2560×1080)

Também foram realizados ajustes específicos para telas menores que **768px** e **576px**, garantindo melhor leitura e navegação.
